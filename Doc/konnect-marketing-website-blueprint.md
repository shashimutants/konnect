## Reference Notes
- **Design DNA (konnectmarketingusa.com):** numbered 01–06 capability cards, dark/light section contrast, bold two-line hero statement with a single CTA, animated stat counters, client-logo trust strip, closing CTA band. The live URL is currently the unconfigured theme demo (placeholder logos, lorem ipsum, fake NY/Paris office blocks) — this blueprint keeps the visual system and replaces every placeholder with real Konnect structure and copy.
- **Structural DNA (speedpro.com):** persistent header locator tool (their zip-code studio finder, adapted below to a state-coverage lookup), dual-axis navigation (browse by Service AND by Industry), named project cards tagged with city/state, and a two-track CTA split.

- **Traditional Agency Model vs. Konnect Modular Model:**

| | Traditional Model | Konnect Modular Model |
|---|---|---|
| Onboarding | Repeats with every new vendor | Once, ever |
| Vendor count as you scale | Grows per channel/state | Stays at one |
| Contract flexibility | Locked multi-year | Phased, performance-gated |
| Reporting | Fragmented per vendor | Unified dashboard |
| Procurement risk | High (multiple MSAs) | Low (single MSA, staged SOWs) |

- **Procurement FAQ:** "What's the minimum engagement?" / "How do you measure performance before Phase 2?" / "One MSA or multiple?" / "Can we pilot in a single state only?"

## SECTION 4 — CONVERSION OPTIMIZATION & CALL FLOW STRATEGY

### CTA & Call Flow — 5 Recommendations

1. **Mobile:** sticky bottom bar, two buttons — `[Call Now]` + `[Get Quote]` — persistent at every scroll depth. **Desktop:** CTA stays in the fixed header; phone number lives in the utility bar, never buried in a menu.
2. Use a **trackable, dynamic phone number** (CallRail-style) sitewide so every source — organic, GMB, paid — gets clean call attribution, reinforcing the same attribution story the brand sells.
3. Vary the CTA verb by funnel stage: top-of-funnel pages → "Learn More" / "See How It Works"; bottom-of-funnel pages (service pillar, contact) → "Get a Quote" / "Talk to a Strategist." One generic CTA everywhere flattens intent signals.
4. On mobile, put **click-to-call above the form**, not below — signage/OOH searches skew local-intent and convert by call far more than by form fill. Desktop can stay form-first.
5. Add a **scroll-depth-triggered secondary CTA** (e.g., past 60% on a service page): a slide-in offering a call or email capture for users who won't complete a full form.

### GMB & Local SEO — 5 Recommendations

1. Build GMB service-area profiles aligned to the states actually served, each pointing to a matching state/region landing page (Phase 2 build) instead of the generic homepage.
2. Match GMB's primary category and services list exactly to the 6 service-pillar names, giving Google's local pack direct one-to-one relevance to the site structure.
3. Turn every completed project (Section 2.6 / 3.3 cards) into a GMB post + review request — same asset, two jobs.
4. Use a **separate call-tracking number on the GMB listing** from the one on the website, so GMB-originated calls are cleanly isolated in reporting from web-originated calls.
5. Publish state/region landing pages with unique, non-duplicated copy and an embedded map — the single highest-leverage local SEO lever for a multi-state business, and a direct extension of "start by region" from the Modular Engagement Model itself.
